# TriviaBuster

An old Java Discord bot that listened for trivia in a designated channel. It was designed for the quiz flow in Red and its CornyBot fork, not for arbitrary Discord bots.

> **Scope:** It can encounter arbitrary quiz questions within that channel; it is not a platform-wide trivia tool.

## Table of Contents

- [Project notes](#project-notes)
- [Technologies](#technologies)

## Project notes

The source preserves an experiment in reacting to chat-based quizzes. Use private or consented test fixtures when studying it; do not disrupt active games or other servers.

## Technologies

- [Java](https://www.oracle.com/java/) and [Maven](https://maven.apache.org/) for the project.
- [Javacord](https://javacord.org/) for Discord events.
- [Red Discord Bot](https://github.com/Cog-Creators/Red-DiscordBot) for the original quiz context.
